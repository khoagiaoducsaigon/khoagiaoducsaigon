# Video Remotion – Chương 2: Loại hình du lịch & Sản phẩm du lịch

Video hoạt hình 60 giây (1920×1080, 30 fps), nhạc nền vui tươi 124 BPM tự tổng hợp (không bản quyền).

| Giây | Cảnh |
|---|---|
| 0–5 | Mở đầu: Chương 2, máy bay bay ngang |
| 5–12 | Khái niệm loại hình du lịch + 7 tiêu chí phân loại |
| 12–21 | Du lịch thuần túy: tham quan, giải trí, nghỉ dưỡng, mạo hiểm, lễ hội |
| 21–29 | Du lịch kết hợp: công vụ, chữa bệnh, thăm thân, thể thao, tôn giáo, sinh thái |
| 29–37 | Sinh thái – Văn hóa – Cộng đồng (Luật DL 2017) + MICE |
| 37–44 | Sản phẩm du lịch = Tài nguyên + Hàng hóa & dịch vụ |
| 44–51 | 5 đặc thù: vô hình, không đồng nhất, đồng thời, thời vụ, không lưu trữ |
| 51–57 | Mô hình 4S, 3H, 6S |
| 57–60 | Kết thúc |

```bash
npm install
python3 scripts/make_music.py public/nhac-nen.wav   # tạo lại nhạc (cần numpy), rồi đổi sang mp3 bằng ffmpeg
npx remotion studio      # xem/sửa trực tiếp
npm run render           # xuất out/du-lich-chuong-2.mp4
```
